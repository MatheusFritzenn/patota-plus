Patota+ — Dependências Instaladas

Documentação de todas as bibliotecas utilizadas no projeto

Frontend (frontend/vite-patota-plus)

Biblioteca Tipo Para que serve
react Produção Biblioteca principal para construção da interface do usuário com componentes reutilizáveis.
react-dom Produção Responsável por renderizar os componentes React no navegador (DOM).
react-router-dom Produção Gerencia a navegação entre telas (rotas) sem recarregar a página. Permite criar uma Single Page Application (SPA).
axios Produção Cliente HTTP para fazer requisições à API do backend (GET, POST, PUT, DELETE). Mais prático que o fetch nativo.
@supabase/supabase-js Produção SDK oficial do Supabase. Utilizado para autenticação (login, cadastro, recuperação de senha, gerenciamento de sessão).
react-icons Produção Biblioteca com milhares de ícones prontos (FontAwesome, Material, Feather etc.) para usar como componentes React.
vite Desenvolvimento Ferramenta de build e servidor de desenvolvimento. Compila o código React rapidamente e oferece hot reload.
tailwindcss Desenvolvimento Framework CSS utilitário. Permite estilizar elementos diretamente no JSX com classes como "bg-blue-500", "text-center", "md:flex".
@tailwindcss/vite Desenvolvimento Plugin que integra o Tailwind CSS ao Vite, processando as classes automaticamente durante o build.
eslint Desenvolvimento Ferramenta de análise estática de código. Identifica erros e padrões inconsistentes no JavaScript/JSX.
@vitejs/plugin-react Desenvolvimento Plugin do Vite que habilita suporte a JSX, Fast Refresh e outras funcionalidades específicas do React.

Backend (backend)

Biblioteca Tipo Para que serve
express Produção Framework web para Node.js. Cria o servidor HTTP, define rotas (APIs) e gerencia requisições/respostas.
@prisma/client Produção Cliente gerado pelo Prisma para acessar o banco de dados PostgreSQL. Permite fazer queries tipadas e seguras.
dotenv Produção Carrega variáveis de ambiente do arquivo .env para process.env. Usado para guardar senhas e URLs sem expor no código.
cors Produção Middleware que permite o frontend (rodando em outra porta/domínio) fazer requisições ao backend. Sem ele, o navegador bloqueia as chamadas.
jsonwebtoken Produção Biblioteca para verificar tokens JWT. Usada no middleware de autenticação para validar que o usuário está logado via Supabase.
prisma Desenvolvimento CLI do Prisma. Usada para criar migrations, gerar o client, visualizar o banco e executar comandos administrativos do ORM.
nodemon Desenvolvimento Reinicia o servidor Node.js automaticamente toda vez que um arquivo é alterado. Evita ter que parar e rodar "node server.js" manualmente.
@types/node Desenvolvimento Definições de tipos TypeScript para o Node.js. Necessário para o editor reconhecer variáveis como "process" sem erros.

Como tudo se conecta

Fluxo Tecnologias envolvidas
Usuário acessa a aplicação no navegador React + Vite + Tailwind CSS
Navega entre telas sem recarregar a página React Router
Faz login ou cadastro Supabase JS SDK (frontend)
Frontend chama a API do backend Axios → Express (com CORS habilitado)
Backend valida se o usuário está autenticado jsonwebtoken (middleware)
Backend consulta/grava dados no banco Prisma Client → PostgreSQL (Supabase)
Variáveis sensíveis ficam protegidas dotenv + arquivo .env
